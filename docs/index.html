solana-priority-fee

Solana priority fee estimator for JavaScript

The compute unit price recent Solana blocks landed at, scoped to the pool or bonding curve your transaction writes to, as percentiles and levels, plus the Compute Budget instruction bytes to pay it. Any RPC. Zero dependencies.

What it does

  • Percentiles (min, p25, p50, p75, p90, p95, max) of the last ~150 blocks, in micro-lamports per compute unit
  • Scoped to up to 128 writable accounts, so you see the price for your pool, not the whole network
  • Named levels low / medium / high / veryHigh, each one changeable
  • The lamport cost, rounded the way the runtime rounds it
  • The SetComputeUnitLimit and SetComputeUnitPrice instruction bytes, without @solana/web3.js
  • Works with any Solana RPC, including the free public one

Use it in your code

npm install github:blixvip/solana-priority-fee
import { estimatePriorityFee, toInstructionsData, costLamports } from "solana-priority-fee";

const fee = await estimatePriorityFee({ accounts: ["58oQChx4yWmvKdwLLZzBi4ChoCc2fqCUWBkwMihLYQo2"] });
fee.recommended.high;                        // p75, micro-lamports per CU
costLamports(fee.recommended.high, 200_000); // lamports on top of the base fee
toInstructionsData(fee.recommended.high, 200_000).instructions; // the two Compute Budget instructions

Ready-made integrations

  • HTTP fee endpoint: GET /fee?accounts=... returns the estimate as JSON, cached for two seconds, on plain node:http.
  • Discord fee alert: posts to a channel webhook when fees on an account cross your threshold, and again when they come back down.

Full documentation, the API and the limits are in the README. MIT licensed, no dependencies.
